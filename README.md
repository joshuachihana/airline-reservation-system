# Airline Reservation System

This project is developed for **practice and learning purposes**.

The main goal is to learn and practice:

* Database design and relationships
* Python and Django development
* REST API development with Django REST Framework
* Airline reservation system architecture
* Managing airlines, airports, aircraft, and seats
* Flight scheduling and flight instance management
* Passenger and customer management
* Reservation and ticketing workflows
* Payment management
* Backend system design and business logic

**This is an educational project and is not intended for real-world airline use.**
